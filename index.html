QTemp 指標計算方法

價格還原與技術指標

調整係數 = Adj Close / Close；還原 O/H/L = 原始 O/H/L × 調整係數 RSI₁₄ = 100 − 100/(1 + Wilder平均漲幅 / Wilder平均跌幅) CCI₂₀ = [Close − SMA₂₀(Close)] / [0.015 × 平均絕對偏差₂₀(Close)] M = [1(RSI>60) − 1(RSI<40) + 1(CCI>100) − 1(CCI<−100)] / 有效指標數

趨勢、量能與分位

EMAₙ(t) = [2/(n+1)]Close(t) + [1−2/(n+1)]EMAₙ(t−1) T = sgn(EMA₅₀−EMA₂₀₀)；F = sgn(EMA₂₁(累積方向成交量)的變化) C = [45T + 35 × 方向(M, ±0.25) + WᵥF] / [45 + 35 × 有效動能 + Wᵥ]；Wᵥ = 0 或 20 D = ln(Close/EMA₂₀₀)；Pᴅ = MidRank(D, 過去504根) Pᴇ = MidRank(ln(Close/EPS), 過去756根)；未提供 EPS 時 P/E 權重 = 0 W = 35 + (Pᴅ有效 ? 50 : 0) + Wₚ B = [35C + (Pᴅ有效 ? 50(2Pᴅ−1) : 0) + Wₚ(2Pᴇ−1)] / W S = EMA₃(B)；QTemp = clip[100 × (MidRank₅₀₄(S)−0.5)/0.45, −100, 100]

有效歷史分位樣本不足30筆時，QTemp = 100 × S；MidRank 對相同值計入中間名次。

訊號判斷

低估值：RSI<30 且 QTemp<−90；高估值：RSI>70 且 QTemp>90 底背離：價格低點更低、QTemp 低點更高；頂背離：價格高點更高、QTemp 高點更低

背離樞紐以左右各3根 K 棒確認，跨度12–90根，另檢查 K 棒方向、指標分數及連線有效性；僅採已確認收盤日 K。
