# QTemp Analytics

以真實 Yahoo Finance 已確認日線為基礎的 QTemp 量化研究平台。提供行情圖表、訊號研究、策略投入回測、多資產比較、自選股及資料品質檢查。**不提供即時保證報價、交易執行或投資建議。**

線上網站：https://qtemp-backtest.onrender.com/

## 金融市場與 EquationNews 快訊中心

市場首頁提供主要收盤行情、跨資產比較、產業 ETF 與最新市場快訊。原 QTemp 圖表、區間、訊號、回測與自選股可用原本的頁面連結。

- 快訊中心使用 EquationNews 公開 REST API 的頻道、列表與單則快訊端點，支援全部 14 個已列出的頻道、列表來源篩選、幣種、近 30 天關鍵字、分頁與中英文切換。頻道列表也會讀取 API 新增的頻道。
- 主頻道以 WebSocket 提醒瀏覽器重新取得 REST 資料，並使用定時更新補漏。其他頻道由 REST 定時更新。以快訊編號去重，支援快取 ETag、斷線退避與 429 避讓。
- 單則資料按實際回應顯示可用語言、公告全文、原始連結、圖像、Telegram、事件結構化欄位與來源 AI 內容。異動資料可包含價格、未平倉量、成交量、資金費率；僅在來源提供時顯示。
- 每個快訊頻道有 RSS 訂閱入口，有 Telegram 連結也會顯示。Fed、SEC 既有公告保留於「機關公告」。EquationNews MCP 與 REST 提供相同快訊資料，網頁使用 REST 供瀏覽器查詢。
- 快訊以台北時間顯示。市場行情沿用 Yahoo Finance 已確認日線，交易日期依標的市場而定；快訊時間與行情日期各自標示。

EquationNews 文件：https://eqn.news/api-docs

## QTemp 七區間歷史分布與連續性統計（2026-11-17）

`#zones` 的「歷史區間天數與占比」已改為真實有效日 K 的**七段互斥區間比例條＋緊湊統計表**，不再使用七張大卡片。固定分數定義如下，左右端點遵守數學區間，不重複分類：

- 極端低估：`[-100,-95)`
- 低估區間：`[-95,-75)`
- 偏弱區間：`[-75,-35)`
- 中性區間：`[-35,35]`
- 偏強區間：`(35,75]`
- 高估區間：`(75,95)`
- 極端高估：`[95,100]`

**QTemp = 100 高風險極值**另以標示顯示當前是否達到，及在選定歷史期間中的天數與占比；已包含在「極端高估」區間內，**不計為第八區**。

選擇近 1／3／5／10／15 年或「全部歷史」時，數值與占比、年度熱力圖、經驗分數直方圖和連續性統計會同步依選取的有效確認日 K 重新計算。當未取得足夠資料時應顯示明確錯誤，不補值。統計包含每個區間天數、有效交易日占比、歷史進入段數、平均連續日數、最長連續日數。一般週末或休市並非交易日空白，無效日／暖機日會中斷連續序列；區間選取起點有可能截斷完整連續段，屬截斷樣本。

可切換至獨立的**歷史百分位模式**，以所選完整期間所有有效分數的平均名次計算（相同數值使用相同名次）。七個百分位帶為 `[0,5)`、`[5,20)`、`[20,40)`、`[40,60]`、`(60,80]`、`(80,95]`、`(95,100]`。相同分數可能造成比例不等於理論切分值，並非錯誤。此模式是**回顧性分布**：歷史日期的排名使用所選期間完整資料（包括該日之後資料），不能作為當時可得的無前視交易訊號。100 分高風險標記仍以原始分數計算。

所有統計僅讀取 QTemp 既有計算輸出，**不改動 `qtemp_core.py` 公式**。新測試於 `test_qtemp_zones.py` 覆蓋分數邊界、總天數與占比互斥、等於 100 單點、高低區連續段、缺失暖機日、期間切換、百分位同分規則及年度總計。

金融市場 `#markets` 改為高資訊密度的**九個全球股票指數網格 + 四個雙欄跨資產群組 + 產業 ETF 密集列表 + 可切換標的走勢圖**，避免單一標的占據大面積卡片。SOX（`^SOX`）仍維持藍紫色特殊強調，SOXX 另列為 ETF。桌面使用均衡雙欄；平板與手機自動降為單欄與兩欄卡片。

資料查詢透過受限執行緒與三分鐘快取限制流量；增加標的後，部分 Yahoo 查詢可能失敗，該標的會顯示無資料，不會假設成交價。

## 行情更新與資料時效（2026-11-16）

- 金融市場首頁及走勢圖的伺服器暫存縮短至 **180 秒**，前端在可見狀態約每 **120 秒**檢查更新；使用者也可在市場資料狀態列按「立即重新檢查」。網站回到前景亦會確認是否需要更新，避免長時間開著頁面不動。
- 市場 API 回傳 `Cache-Control: no-store`，避免瀏覽器或中間層凍結舊版 JSON。首頁僅傳最後成交日與漲跌幅、少量關鍵資料；圖表需要時才查詢完整歷史。
- **資料擷取時間不等於收盤日期**：每張行情卡都保留實際來源的日 K 日期。若來源日期落後預期的最近平日收盤日，額外標記「可能過期」；因市場休市日與節假日不同，這是警示，不直接宣稱抓取故障。
- QTemp 經驗證歷史行情快取縮為三分鐘，日 K 收盤更新檢查縮為兩分鐘。若 Yahoo Finance 無法更新，仍可使用已標記的過期備援資料，不會把過期快取偽裝成最新行情。
- 台灣時間 2026-11-16（週一）晚間，美股完整日 K 最近交易日仍為 **11/13（週五）**；美股 11/16 收盤日的完整資料最早須待台灣時間 11/17 清晨之後。台灣股市 11/16 則應核對該日收盤資料是否已公開。
- 更新頻率不能提高市場行情來源的發布速度，Yahoo Finance 仍可能因延遲或流量限制而無法提供最新報價；若需要即時盤中行情，需採用有公開展示權限的授權即時行情資料源。

## 現行網站架構（2026-11-14）

舊版六入口已整合至 **量化研究**，首頁已改為全球金融市場總覽，現行八個入口見上方。歷史「區間統計」已整合於**訊號研究 → 區間統計**；研究資源（資料品質、公式、TradingView CSV 對照、匯出）從頁首 **資料與說明** 或頁尾入口進入。原 `#zones`、`#resources` 連結仍可使用，避免舊分享連結失效。

- **總覽**：目前標的、QTemp 分數、歷史百分位、最新區間狀態與資料截止日。重複的完整分布圖與熱力圖不在總覽展示。
- **行情圖表**：確認日 K、還原 OHLC、QTemp、訊號標記、技術圖表拖曳與區間縮放、PNG 匯出。
- **訊號研究**：歷史勝率、訊號事件研究、訊號日曆、年度統計與 QTemp 分數區間。QTemp 分數區間包含歷史直方圖、年度天數熱力圖與目前分數位置。
- **策略回測**：QTemp「低估值」確認後下一交易日開盤追加固定金額、定期定額、期初單筆投入三種只買不賣策略。提供 XIRR、資金流調整後風險、買入交易明細與 CSV。
- **標的比較**：最多四個資產、SPY/QQQ/SOXX 基準、長期及自訂期間、同日配對績效、相關矩陣與可選再平衡組合；預設表只展示核心報酬風險，低頻使用的 Sortino、Calmar、Beta、Alpha 等保留於可展開「進階統計」。
- **自選股**：本機儲存分組、備註、排序、查詢及 JSON 匯入／匯出；通知有兩類：*分數低於門檻的區間提醒*（不等於新訊號）與*最新已確認日 K 當天的新訊號*。排除暫算訊號，兩類去重獨立。

## 主要金融計算與資料限制

- 歷史行情使用 Yahoo Finance 已確認日 K，計算與比較使用 **Adj Close 比例還原的 OHLC**。未取得資料的日期不補虛構價格，不保證即時行情；快取與過時備援會在資料品質頁標示。
- QTemp 核心公式保留於 `qtemp_core.py`，未經本次網站精簡改動。確認日訊號在收盤成立；回測按下一交易日還原開盤價執行，不用未來資料。
- 最佳／最差年度報酬僅納入具備**前一年底收盤基準**、同一曆年首末完整範圍與足夠共同交易日的年度；不完整年度顯示空值，而非冒充全年報酬。
- 三策略日報酬採**入金時間分段的時間加權計算**：日初投入計入當日盤中，日末投入不計當日報酬；原持股透過開盤市值區分隔夜和日內變動。無持倉時不得產生虛假報酬。XIRR 仍以實際現金流與期末市值計算。
- 多資產資料以所有標的與基準的共同有效交易日配對；年化 Sharpe/Sortino/Alpha 使用 252 日和零無風險利率。不同幣別未換匯，槓桿 ETF 每日重設且可能有波動耗損；組合模擬不計費用、稅、滑價、融資及限制。
- 監控面板是**目前回應程序自啟動後**的 API 使用與錯誤次數，不是全站或 Yahoo 整體 SLA。Render 重新部署／程序重啟會歸零。
- 自選股資料只存在目前瀏覽器，請使用 JSON 匯出備份。網站開啟且使用者允許時才可能發送瀏覽器通知，不代表伺服器會持續監控。

## 技術構成

- `app.py`：Flask API 與前端資源服務。
- `qtemp_core.py`：原始 QTemp、訊號、日線還原、TradingView CSV 對照。
- `research_features.py`：共用 QTemp 快取與自選股確認訊號掃描。
- `capital_backtest.py`：長期三策略與資金流績效。
- `deep_comparison.py`：多資產報酬、風險、相關與組合。
- `research_insights.py`、`qtemp_zones.py`：資料品質、事件研究、訊號與區間統計。
- `index.html`、`platform_navigation.js`、`workspace_glass.css` 及各功能 UI/樣式：多頁導覽；新版市場與快訊樣式位於 `static/market_terminal.css`。
- `market_cache.py`：已驗證 Yahoo 歷史日線 JSON 暫存，短期快取與最多七天的可標示過時備援。Render `/tmp` 非永久儲存，不能保證部署後有備援。
- `.github/workflows/qtemp-ci.yml`：Python 編譯、JavaScript 語法、金融計算及 Flask 路由煙霧測試。

已淘汰舊版固定近五年 `compare_assets` API 和舊單倉買賣 `strategy` API，以免與正式多資產比較／長期投入回測採用不同口徑。**TradingView CSV 的 `compare` API 仍保留，供指標計算核對。**

## 本機啟動與驗證

```bash
pip install -r requirements.txt
python -m unittest -v test_capital_backtest test_deep_comparison test_financial_audit test_watchlist_audit test_research_insights test_market_cache test_qtemp_zones
python -m flask --app app run
```

開啟 http://127.0.0.1:5000 。CI 只涵蓋確定性、離線測試；仍需獨立確認 Render 健康檢查、Yahoo Finance 連線、瀏覽器互動及實際行情口徑。離線測試的合成價僅供演算法驗證，**不會成為公開網站顯示行情**。
